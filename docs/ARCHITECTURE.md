# 架构说明

```text
车主H5 / 运营端 / 支付网关
            ↓
        HTTP API层
            ↓
场站 ─ 设备 ─ 预约 ─ 会话 ─ 计费 ─ 钱包 ─ 运维
            ↓                 ↓
       JSON/MySQL         审计与指标
            ↑
     OCPP设备适配层
```

社区版在单进程内实现领域状态机，并用 JSON 快照持久化，便于学习完整流程。生产部署应将 OCPP 长连接、交易API、计费账本和查询报表拆分，并使用 MySQL、Redis、消息队列、时序数据库与对象存储。

关键一致性边界：启动会话和枪状态同事务；表计读数按设备顺序消费；计费结果与钱包账本同事务；故障工单与设备禁用保持一致。金额使用 `DECIMAL`，时间统一保存 UTC 并在展示层转换时区。
